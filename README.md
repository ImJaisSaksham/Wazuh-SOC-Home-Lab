# Wazuh SOC Home Lab

## 📌 Project Overview

This project demonstrates the deployment of a small Security Operations Center (SOC) environment using Wazuh for security monitoring, log collection, and threat detection.

## 🎯 Objectives

- Understand SIEM architecture.
- Monitor Windows and Linux endpoints.
- Collect and analyze security logs.
- Investigate suspicious authentication activity.
- Understand security alert generation.
